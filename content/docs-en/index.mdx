**mkan** is a home-rental platform: apartments, villas and rooms, by the night or by the month. It started in Sudan and today runs mainly in Kigali, Rwanda.

## The listing code

Every listing has a code shaped `NNNN-NN`: the first four digits are the host's account number, the last two the unit. The same code appears in the listing URL, in outreach messages and in the CRM.
