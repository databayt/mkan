# Mkan

Mkan is a rental marketplace that connects tenants with property managers, offering a seamless experience for discovering, touring, and securing rental properties. Built with Airbnb-inspired design patterns.
<br>

Credit: [Airbnb](https://airbnb.com)

## Documentation

Visit https://www.mkan.sd/en/docs to view the documentation (Arabic at `/ar/docs`). The pages live in
`content/docs-en/` and `content/docs-ar/`.

- [How mkan works](https://www.mkan.sd/en/docs/pipeline): scrape, enhance, post, chat.
- [Mkan agent](https://www.mkan.sd/en/docs/chatbot): the agent on the site and on WhatsApp.
- [Chat funnel](https://www.mkan.sd/en/docs/chat-funnel): how the chat takes a tenant from the first message to a
  viewing, and how we measure it. The full analysis is in [`docs/chat-funnel.md`](docs/chat-funnel.md), and the code
  is in [`src/components/agent/`](src/components/agent/README.md).
