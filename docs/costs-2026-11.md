# mkan — what Cloudflare really costs (2026-11-05)

/monetize charged Cloudflare at **$1 a month** (mkan's share of the $5 Workers Paid plan). That left out
the biggest line: mkan runs an **always-on Cloudflare Container** (`wrangler.jsonc`: `MkanContainer`,
`instance_type: standard-1`, `max_instances: 1`). The 10-25 container cut kept containers for hogwarts
and mkan only.

## The arithmetic (Cloudflare Containers pricing, page dated 2026-10-05)

standard-1 = ½ vCPU, 4 GiB memory, 8 GB disk. Memory and disk bill on what is **provisioned**,
every second the container is up; CPU bills on **active** use only. 30 days = 720 h.

| Line | Usage | Included (Workers Paid) | Billable | Rate | Month |
|---|---|---|---|---|---|
| Memory | 4 GiB × 720 h = 2,880 GiB-h | 25 GiB-h | 10,278,000 GiB-s | $0.0000025 / GiB-s | **$25.70** |
| CPU | ~5% of 1 vCPU = 2,160 vCPU-min | 375 vCPU-min | 107,100 vCPU-s | $0.000020 / vCPU-s | **$2.14** |
| Disk | 8 GB × 720 h = 5,760 GB-h | 200 GB-h | 20,016,000 GB-s | $0.00000007 / GB-s | **$1.40** |
| **Container total** | | | | | **≈ $29.24** |

Plus mkan's $1 share of the $5 Workers Paid plan → **≈ $30.24 / month ≈ 43,850 RWF** (at 1,450 RWF/$).
The CPU share is an estimate; memory dominates and is exact while the container never sleeps.

## What it changes

- Fixed costs on /monetize: Cloudflare $1 → **$30.24**; break-even ≈ **$37 / month** (was ≈ $8).
  The page's default now uses this figure (`src/lib/monetize/costs.ts`).
- Proposed `MONETIZE_FIXED_COSTS_RWF` once the SIM and Mac numbers are confirmed:
  `{"cloudflare":43850,"whatsappLine":5000,"macAndInternet":3000}` — Abdout to confirm the last two.
- **Lever:** mkan on a plain Worker (OpenNext, like food / marketing / codebase / kun since 10-25)
  removes the $29.24 container line — break-even back to ≈ $8. An unfinished migration for exactly
  this sits uncommitted in the repo; finishing it is worth more than any other cost line.
